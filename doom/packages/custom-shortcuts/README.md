# custom-shortcuts

The larger, non-trivial **custom shortcuts** and the helper commands they call
(project-root default directory, structural move up/down, opening a Ghostel
terminal with `` C-` ``, ...) — pulled out of config.org's main keybindings
section so that section stays a quick, scannable list.

Extracted verbatim from config.org's *Keybindings › Custom Shortcuts* section.

## Loading

`config.org` loads it in place with `(mp/require-package "custom-shortcuts")`.
