This is the *single source of truth* for the Quickshell "pill". The QML lives in
[[*Source][§ Source]] as literate tangle blocks; editing them here and tangling
regenerates the =.qml= files. Read [[*How the pill works][§ How the pill works]]
before touching code, and keep this file in sync with the running pill — they are
a pair.

* The brief (what I was asked to build)

Replace KDE's default panels with a Quickshell "pill":

- A *pill* at the *top-center*, *always on top*, *not* reserving screen space;
  hidden only when a fullscreen window is focused.
- *Collapsed*: only essential info — a notification transforms the pill;
  otherwise system tray + icons of open apps that have a notification, else time.
- *Hovered*: original info hides, pill transforms — *virtual-desktop dots*
  top-left (filled = focused, click to switch), *active apps* top-right (pin-able
  ideally), *system tray* below the apps, *time* below the desktops.
- *Clicked*: expands further into a *control panel*. The tray side always shows
  network/volume/bluetooth/battery/notification icons; clicking one swaps the
  pane below (default = notification history) for that icon's menu:
  - *network*: pick Wi-Fi + VPN like KDE's applet.
  - *volume*: Devices tab (mic + speaker) and Applications tab; pick the active
    device, change any volume.
  - *bluetooth*: connected on top, divider, paired, then discovered.
  - *battery*: battery of all supported devices.
- Clicking *outside* only collapses the pill; the click is *not* passed through.

Constraints: prefer KDE/system APIs over writing our own; review docs, don't
guess; if a thing can't be backed by a source, say so. Reference rice:
[[https://github.com/Gakuseei/Ricelin][Gakuseei/Ricelin]] (Hyprland-only — its
workspace/taskbar code does not port to KWin; design/animation ideas do).

* Environment (verified, not assumed)

| Thing               | Value                                            |
|---------------------+--------------------------------------------------|
| Quickshell          | 0.3.0 (Arch), binary =qs= / =quickshell=         |
| Qt                  | 6.11                                             |
| Desktop             | KDE Plasma 6.7.1, KWin, Wayland                   |
| Audio / Power       | Pipewire, UPower — active                         |
| Network / Bluetooth | NetworkManager 1.56, BlueZ — active               |

*Critical compositor fact* (=wayland-info=): KWin advertises =zwlr_layer_shell_v1=
and =org_kde_plasma_virtual_desktop_management=, but NOT =ext_workspace_v1=,
=zwlr_foreign_toplevel_manager_v1=, or =org_kde_plasma_window_management=. So
Quickshell's =WindowManager= and =Wayland.ToplevelManager= exist but *don't
function* here — virtual desktops go through KWin DBus, and the taskbar /
fullscreen-hide are blocked on there being no client-visible window-list protocol.

The taskbar needs no Wayland window protocol: KWin's KRunner "windows" runner lists
and activates windows over DBus, and a tiny KWin script reports the active window
(see =winbridge.py=). Remaining: *launcher actions* (blocked on =DesktopEntries=
returning entries), *pinned apps* (app-side state), *VPN* (needs nmcli),
*fullscreen-hide* (wireable now via =getWindowInfo=), and *notifications* (would
require taking the DBus name from Plasma).

* How the pill works

The shell is split into small files (see [[*File map][§ File map]]). Sibling
=.qml= files are usable as component types via QML's implicit directory import.
=Theme= is instantiated once in =init.qml= and passed to each menu as a =theme=
property (no singletons, so nothing magic to set up).

** Window & input model (init.qml)
=Variants { model: Quickshell.screens }= makes one =PanelWindow= per monitor. Each
window is a *full-screen* layer-shell =Overlay= surface that reserves no space.
Input is governed by the window =mask=:
- *collapsed / hovered*: =mask= = a =Region { item: pill }= → only the pill
  rectangle catches clicks; the rest of the screen passes through.
- *open / launcher / right-click menu*: =mask= = a =Region { item: backdrop }=
  (the whole window) → outside clicks are caught by a backdrop =MouseArea= that
  closes the panel, so the click is swallowed, never passed through.

** Stages
A single =pill= =Item= animates =width=/=height= between the stages via
=Behavior=; cross-fading content layers (=opacity= + =visible=) show/hide per
stage:
1. *collapsed* (96×28): just =hh:mm=.
2. *hovered* (=dash=, 384×104): dashboard — *two balanced rows*. Row 1: desktop
   dots (left) | grouped app icons (right). Row 2: an app-launcher button +
   date/time (left) | status icons
   (network/volume/bluetooth/battery/notifications, icon-only, click → open that
   menu) + system tray (right). =dash= is true when hovered, open, or a
   right-click menu is up.
3. *open* (470 tall): control panel. Row 1 *and* Row 2 stay on top — Row 2 now
   doubles as the *menu switcher* (the active menu's status icon is highlighted);
   there is *no icon rail*. Below a divider sits a single full-width menu pane: a
   =Loader= shows the menu component for =win.menu= (=active= only while open).
   Each menu renders a shared =MenuHeader= — a back chevron that collapses the
   panel via the menu's =closeRequested()= signal (wired through a =Connections=
   on the loader), the title, and a trailing slot for the menu's own toggles.
   Clicking the pill body sets =open=; a =MouseArea= swallows clicks on empty pill
   area so they don't reach the close-backdrop.
4. *launcher* (=launcher=, 520×470): the app launcher replaces the menu pane (see
   [[*Launcher.qml][§ Launcher.qml]]). Opened from the Row-2 grid button; while
   =open= or =launcher= the layer surface takes =WlrKeyboardFocus.OnDemand= so the
   search field can receive keystrokes.

The window =mask= also expands to full-screen when an app *right-click menu* is
open (=win.ctxGroup=), so that menu (a =Loader= floating below the pill) is
clickable and an outside click dismisses it.

** Open windows / taskbar (winbridge.py)
KWin advertises no window-list protocol and no active-window over DBus, so
=winbridge.py= (run as =python <shellDir>/winbridge.py=) glues two KDE APIs and
prints one JSON line =\{active, windows\}= per update on stdout, which a =Process= +
=SplitParser= parses into =root.windows= / =root.activeWindow=:
- *window list*: the KRunner "windows" runner =org.kde.KWin /WindowsRunner=,
  =org.kde.krunner1.Match("")= returns every window =(id, title, icon, …)= (icon is
  already an app-icon name like =org.kde.dolphin=); polled ~1 s, deduped by id
  (the runner returns each window twice). =Run(id, "")= focuses one.
- *active window*: the helper owns DBus name =org.kde.pill= and loads a 3-line KWin
  script (via =/Scripting=) that calls us on =workspace.windowActivated= with
  =String(window.internalId)= (=\{uuid\}=, matching the krunner ids). Unloaded on exit.

In the UI, =root.appGroups= groups windows by =icon= (one tile per app, with a
count badge for ≥2 windows and an underline that turns accent when any of the
app's windows is active). Left-click =cycleGroup= focuses the app's next window;
right-click opens a floating menu (this app's windows to focus + launcher actions
from =DesktopEntries.heuristicLookup(icon).actions= when available).

** Virtual desktops (init.qml, DBus)
Three =Process= blocks drive =gdbus= against =org.kde.KWin /VirtualDesktopManager=:
fetch the =desktops= list (a regex parses =(uint32 N, 'id', 'name')= tuples — the
=uint32= tag is optional because gdbus only prints it on the first tuple), fetch
=current=, and =gdbus monitor= the =currentChanged= signal so the dots stay live.
=switchDesktop(id)= sets the writable =current= property.

** Menus (one file each)
- =NetworkMenu=: finds the Wi-Fi =NetworkDevice= (=type === DeviceType.Wifi=),
  lists =device.networks= sorted active-first then by =signalStrength=, shows
  signal bars + a lock for secured nets, connect/disconnect, and a password
  overlay calling =connectWithPsk()= for secured unknown nets. Toggles
  =Networking.wifiEnabled=. Turns the scanner on while visible.
- =VolumeMenu=: a =PwObjectTracker= over every node keeps audio live. Nodes are
  classified by =properties["media.class"]=: =Audio/Sink= (speakers),
  =Audio/Source= (mics), =Stream/Output/Audio= (apps). Per row: name, set-default
  marker (=preferredDefaultAudioSink/Source=), mute, and a =PillSlider= bound to
  =node.audio.volume=.
- =BluetoothMenu=: adapter power + scan toggles (=defaultAdapter.enabled= /
  =.discovering=), then three filtered sections — Connected, Paired, Available —
  each row connect/disconnect/pair via the device methods, with battery % when
  =batteryAvailable=.
- =BatteryMenu=: =UPower.devices= filtered to present, non-line-power devices,
  each with =IconImage { source: Quickshell.iconPath(iconName) }=, name/type,
  state and percentage.

Every menu declares a =signal closeRequested()= and opens with a =MenuHeader=
(back chevron + title + trailing toggle slot); the chevron emits =closeRequested=,
which =init.qml='s =Connections= on the menu loader turns into =win.open = false=.

** Launcher (init.qml + Launcher.qml)
=init.qml= builds =appList= once (=DesktopEntries.applications=, =noDisplay=
filtered, name-sorted) at the long-lived root and shares it with every monitor's
=Launcher=, so opening is instant and survives close. Grid mode + favourite app
ids persist in =Quickshell.stateDir + "/launcher.json"= via a =FileView= +
=JsonAdapter= (=settings=); the adapter auto-flushes on change and is created on
first run (=onLoadFailed → writeAdapter()=). The =Launcher= itself: a focused
search field (matches name/genericName/keywords), a grid/list toggle, ★ favourites
(empty query shows favourites if any, else all apps; searching is always a flat
list), a right-click menu (=DesktopEntry.actions= + favourite toggle), and a
calculator (a safe arithmetic expression, or one prefixed with ===, shows a result
row that =wl-copy='s on click/Enter). =init.qml= focuses + clears the field on each
open via a =Connections= on =win.launcher=.

** Reusable widgets
=PillToggle= (themed switch), =PillSlider= (themed 0..1 slider) and =MenuHeader=
(back chevron + title + trailing slot) keep the menus small and the look coherent.

** PillToggle.qml
#+begin_src qml :tangle ~/.config/quickshell/pill/PillToggle.qml :mkdirp yes
pragma ComponentBehavior: Bound
// PillToggle.qml — a small themed on/off switch. Reusable across menus.
import QtQuick

Item {
    id: root
    required property var theme
    property bool checked: false
    signal toggled(bool value)

    implicitWidth: 34
    implicitHeight: 18

    Rectangle {
        anchors.fill: parent
        radius: height / 2
        color: root.checked ? root.theme.accent : root.theme.bgHover
        border.color: root.checked ? root.theme.accent : root.theme.border
        border.width: 1
        Behavior on color { ColorAnimation { duration: root.theme.animFast } }

        Rectangle {                       // knob — fits inside the track
            width: parent.height - 4
            height: parent.height - 4
            radius: height / 2
            y: 2
            x: root.checked ? parent.width - width - 2 : 2
            color: "white"
            Behavior on x { NumberAnimation { duration: root.theme.animFast; easing.type: Easing.OutCubic } }
        }
    }

    MouseArea {
        anchors.fill: parent
        cursorShape: Qt.PointingHandCursor
        onClicked: {
            root.checked = !root.checked;
            root.toggled(root.checked);
        }
    }
}

// PillSlider.qml — a themed horizontal slider over [0,1]. Reused for volume.
import QtQuick

Item {
    id: root
    required property var theme
    property real value: 0            // 0..1
    signal moved(real value)

    implicitHeight: 16
    implicitWidth: 120

    readonly property real clamped: Math.max(0, Math.min(1, value))

    Rectangle {                       // track
        id: track
        anchors.verticalCenter: parent.verticalCenter
        width: parent.width
        height: 5
        radius: 2.5
        color: root.theme.bgHover

        Rectangle {                   // fill
            width: root.clamped * parent.width
            height: parent.height
            radius: parent.radius
            color: root.theme.accent
        }
    }

    Rectangle {                       // handle
        width: 12
        height: 12
        radius: 6
        color: "white"
        anchors.verticalCenter: parent.verticalCenter
        x: root.clamped * (root.width - width)
    }

    MouseArea {
        anchors.fill: parent
        cursorShape: Qt.PointingHandCursor
        function apply(mx) {
            const v = Math.max(0, Math.min(1, mx / width));
            root.value = v;
            root.moved(v);
        }
        onPressed: mouse => apply(mouse.x)
        onPositionChanged: mouse => { if (pressed) apply(mouse.x); }
    }
}

    required property var theme
    signal closeRequested()

        const ds = Networking.devices ? Networking.devices.values : [];

        return null;

// its desktop actions and a favourite toggle. Favourites + grid mode are

import Quickshell.Io

    required property var apps        // [DesktopEntry], pre-sorted by the parent

    readonly property bool searching: q.length > 0

    function norm(s) { return (s || "").toString().toLowerCase(); }
    readonly property var filtered: {
        if (!searching)
            return [];
        const out = [];
        for (const a of apps) {
            if (norm(a.name).indexOf(q) >= 0 || norm(a.genericName).indexOf(q) >= 0) { out.push(a); continue; }
            const kw = a.keywords || [];
            let hit = false;
            for (const k of kw) if (norm(k).indexOf(q) >= 0) { hit = true; break; }
            if (hit) out.push(a);
        }
        return out;

        return ids.map(id => byId[id]).filter(Boolean);

#!/usr/bin/env python
# winbridge.py — feeds the pill its open-window list + the active window.
#
# Why this exists: KWin (Wayland) exposes NO window-list protocol to clients and
# NO active-window over DBus. So we use two KDE APIs and glue them:
#   * the KRunner "windows" runner (org.kde.KWin /WindowsRunner) lists windows
#     (id, title, app-icon name) and is polled here;
#   * a 3-line KWin script (loaded below via /Scripting) reports the active
#     window's id whenever it changes, by calling our own org.kde.pill service.
# We print one JSON line {"active": "{uuid}", "windows": [...]} per update; the
# pill reads it on stdout. Launched by init.qml as `python <shellDir>/winbridge.py`.
import sys, os, json, atexit, tempfile
from gi.repository import Gio, GLib

bus = Gio.bus_get_sync(Gio.BusType.SESSION, None)
# "taskbar" is the set of window ids that belong in a taskbar (normal, not
# skip-taskbar) as reported by KWin; None until the first report arrives.
state = {"active": "", "taskbar": None}
PLUGIN = "quickshell-pill-active"

# --- our DBus service ---
#   Set(uuid)   — KWin script reports the active window on change
#   List(json)  — KWin script reports the taskbar-eligible window ids (JSON array)
NODE = (
    '<node><interface name="org.kde.pill">'
    '<method name="Set"><arg type="s" direction="in"/></method>'
    '<method name="List"><arg type="s" direction="in"/></method>'
    "</interface></node>"
)
IFACE = Gio.DBusNodeInfo.new_for_xml(NODE).interfaces[0]


def on_call(conn, sender, path, ifc, method, params, inv):
    if method == "Set":
        (u,) = params.unpack()
        state["active"] = u
        emit()
    elif method == "List":
        (j,) = params.unpack()
        try:
            state["taskbar"] = set(json.loads(j))
        except Exception:
            state["taskbar"] = None
        emit()
    inv.return_value(None)


def on_bus_acquired(conn, name):
    conn.register_object("/Active", IFACE, on_call, None, None)
    load_kwin_script()


# --- the KWin script: reports the active window AND the taskbar-eligible
#     window ids (normal windows that don't ask to skip the taskbar). KWin is
#     the only place skipTaskbar is exposed; KRunner (used for icon names) is
#     not. We re-push the list on add/remove and on skipTaskbar changes. ---
KWIN_JS = (
    "function ids(){ var ws=workspace.windowList(), o=[];\n"
    "  for (var i=0;i<ws.length;i++){ var w=ws[i];\n"
    "    if (w.normalWindow && !w.skipTaskbar) o.push(String(w.internalId)); }\n"
    "  return o; }\n"
    'function pushList(){ callDBus("org.kde.pill","/Active","org.kde.pill","List",'
    " JSON.stringify(ids())); }\n"
    "function watch(w){ if (w && w.skipTaskbarChanged) w.skipTaskbarChanged.connect(pushList); }\n"
    'function setActive(w){ callDBus("org.kde.pill","/Active","org.kde.pill","Set",'
    ' w ? String(w.internalId) : ""); }\n'
    "workspace.windowActivated.connect(setActive);\n"
    "workspace.windowAdded.connect(function(w){ watch(w); pushList(); });\n"
    "workspace.windowRemoved.connect(pushList);\n"
    "var all=workspace.windowList(); for (var i=0;i<all.length;i++) watch(all[i]);\n"
    "setActive(workspace.activeWindow);\n"
    "pushList();\n"
)


def kwin(method, variant):
    try:
        bus.call_sync(
            "org.kde.KWin",
            "/Scripting",
            "org.kde.kwin.Scripting",
            method,
            variant,
            None,
            Gio.DBusCallFlags.NONE,
            2000,
            None,
        )
    except Exception as e:
        sys.stderr.write("winbridge: %s failed: %s\n" % (method, e))


def load_kwin_script():
    path = os.path.join(tempfile.gettempdir(), "quickshell_pill_active.js")
    with open(path, "w") as f:
        f.write(KWIN_JS)
    kwin("unloadScript", GLib.Variant("(s)", (PLUGIN,)))  # clear a stale copy
    kwin("loadScript", GLib.Variant("(ss)", (path, PLUGIN)))
    kwin("start", None)


@atexit.register
def _cleanup():
    kwin("unloadScript", GLib.Variant("(s)", (PLUGIN,)))


# --- poll the KRunner windows runner for the window list ---
def windows():
    try:
        res = bus.call_sync(
            "org.kde.KWin",
            "/WindowsRunner",
            "org.kde.krunner1",
            "Match",
            GLib.Variant("(s)", ("",)),
            GLib.VariantType("(a(sssida{sv}))"),
            Gio.DBusCallFlags.NONE,
            3000,
            None,
        )
    except Exception:
        return []
    tb = state["taskbar"]
    seen = {}
    for m in res.unpack()[0]:
        mid, text, icon = m[0], m[1], m[2]  # id, title, icon name
        if not mid.startswith("0_") or mid in seen:
            continue
        uuid = mid[2:]
        # once KWin has reported the eligible set, drop skip-taskbar windows;
        # before the first report, show everything (previous behaviour)
        if tb is not None and uuid not in tb:
            continue
        seen[mid] = {"id": mid, "uuid": uuid, "title": text, "icon": icon}
    return sorted(seen.values(), key=lambda d: d["id"])


def emit():
    line = json.dumps(
        {"active": state["active"], "windows": windows()}, ensure_ascii=False
    )
    sys.stdout.write(line + "\n")
    sys.stdout.flush()


def tick():
    emit()
    return True


Gio.bus_own_name(
    Gio.BusType.SESSION,
    "org.kde.pill",
    Gio.BusNameOwnerFlags.ALLOW_REPLACEMENT | Gio.BusNameOwnerFlags.REPLACE,
    on_bus_acquired,
    None,
    None,
)
GLib.timeout_add_seconds(1, tick)
GLib.MainLoop().run()

#+begin_src sh :tangle ~/.config/quickshell/pill/run-pill.sh :mkdirp yes :tangle-mode (identity #o755)
#!/bin/sh
# run-pill.sh — launch the pill with a Wayland environment resolved at runtime.
#
# After a reboot the login shell often has no WAYLAND_DISPLAY / QT_QPA_PLATFORM
# exported, so Qt falls back to the xcb plugin, fails to connect, and crashes.
# Qt selects its platform plugin before any QML is parsed, so this has to be
# fixed in the launcher rather than in init.qml. We discover the compositor's
# socket from XDG_RUNTIME_DIR and point Qt at it.
#
# Usage:  ./run-pill.sh            (runs quickshell/init.qml next to this script)
#         ./run-pill.sh <args>     (extra args are forwarded to qs)

set -eu

dir=$(CDPATH= cd -- "$(dirname -- "$0")" && pwd)

# XDG_RUNTIME_DIR is where the wayland socket lives; derive it if absent.
: "${XDG_RUNTIME_DIR:=/run/user/$(id -u)}"
export XDG_RUNTIME_DIR

# If we weren't handed a display, find the compositor's socket.
# Prefer wayland-0, else the first wayland-N socket present.
if [ -z "${WAYLAND_DISPLAY:-}" ]; then
    if [ -S "$XDG_RUNTIME_DIR/wayland-0" ]; then
        WAYLAND_DISPLAY=wayland-0
    else
        for sock in "$XDG_RUNTIME_DIR"/wayland-*; do
            case "$sock" in
                *.lock) continue ;;
            esac
            [ -S "$sock" ] || continue
            WAYLAND_DISPLAY=$(basename "$sock")
            break
        done
    fi
fi

if [ -z "${WAYLAND_DISPLAY:-}" ]; then
    echo "run-pill.sh: no wayland socket found in $XDG_RUNTIME_DIR" >&2
    exit 1
fi
export WAYLAND_DISPLAY
export QT_QPA_PLATFORM=wayland

exec qs -p "$dir/init.qml" "$@"
#+end_src

* Tangling (how to regenerate the =.qml= files)

This file owns the code; the =.qml= files *and* =winbridge.py= are *generated*.
=C-c C-v t= (=org-babel-tangle=) tangles *all* blocks at once to their =:tangle=
targets in this directory. (Editing a generated file directly is lost on the next
tangle — change it here instead.) Note: launching the pill makes =winbridge.py=
load a small KWin script (=quickshell-pill-active=); it is unloaded when the
bridge exits. After editing any block:

- In Emacs with this file open: =C-c C-v t=.
- Or batch / shell:
  =emacs --batch -l org -eval '(org-babel-tangle-file "quickshell/qs-pill-docs.org")'=

Then validate:  =qs -p quickshell/init.qml=  (Ctrl-C to stop). A clean load prints
"Configuration Loaded" with no WARN lines.
