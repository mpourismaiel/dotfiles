#+AUTHOR: Mahdi

This is the *single source of truth* for the Quickshell "pill": a literate org
file whose code blocks (see [[*Source][§ Source]]) tangle to the =.qml= files.
Each file's section header explains what it does and why — read those before
touching code, and keep this file in sync with the running pill; they are a pair.

* What this is

A Quickshell replacement for KDE's panels: a single *pill* at the top-center of
every monitor, always on top, reserving no screen space, hidden only while a
fullscreen window is focused. It morphs through four stages — a collapsed clock, a
hovered dashboard (virtual-desktop dots, grouped open apps, status icons, system
tray, date/time), a clicked-open *control panel* (network / volume / bluetooth /
battery / notification-history menus), and an app *launcher*. It is also this
machine's freedesktop *notification daemon* (popups morph the pill; history +
inline reply), and flashes transient *action bursts* on desktop switches and
keyboard-layout changes. Clicking outside only collapses it — the click is not
passed through.

Where KWin exposes no client-visible protocol (window list, active window) the
pill leans on KDE/system APIs over DBus rather than rolling its own — see
[[*Environment (verified, not assumed)][§ Environment]]. Palette and animation
cues are borrowed from [[https://github.com/Gakuseei/Ricelin][Gakuseei/Ricelin]]
(Hyprland-only; its workspace/taskbar code does not port to KWin).

* Environment (verified, not assumed)

| Thing               | Value                                            |
|---------------------+--------------------------------------------------|
| Quickshell          | 0.3.0 (Arch), binary =qs= / =quickshell=         |
| Qt                  | 6.11                                             |
| Desktop             | KDE Plasma 6.7.1, KWin, Wayland                   |
| Audio / Power       | Pipewire, UPower — active                         |
| Network / Bluetooth | NetworkManager 1.56, BlueZ — active               |

*Critical compositor fact* (=wayland-info=): KWin advertises =zwlr_layer_shell_v1=
and =org_kde_plasma_virtual_desktop_management=, but NOT =ext_workspace_v1=,
=zwlr_foreign_toplevel_manager_v1=, or =org_kde_plasma_window_management=. So
Quickshell's =WindowManager= and =Wayland.ToplevelManager= exist but *don't
function* here — virtual desktops go through KWin DBus, and the taskbar /
fullscreen-hide are blocked on there being no client-visible window-list protocol.

* Taking over notifications from Plasma

The pill is a real freedesktop notification daemon (=NotificationServer=, see
[[*Notifications.qml][§ Notifications.qml]]). Only one process may own the bus
name =org.freedesktop.Notifications=, and on this machine that owner is
*plasmashell itself* (the =org.kde.plasma.notifications= tray applet) — registered
*without* =ALLOW_REPLACEMENT=, so the pill cannot grab it at runtime. Plasma must
be stopped from registering it first:

1. System tray ▸ *Configure System Tray…* ▸ *Entries* ▸ set *Notifications* to
   *Disabled* (not "Hidden" — that still loads the applet and grabs the name).
2. Restart the shell: =systemctl --user restart plasma-plasmashell= (or re-login).
3. Start the pill (=./run-pill.sh=); confirm it owns the daemon — =busctl --user
   call org.freedesktop.Notifications /org/freedesktop/Notifications
   org.freedesktop.Notifications GetServerInformation= should report ="quickshell"=.

To hand notifications back, re-enable the tray entry and restart plasmashell.

** Theme.qml
All colours, metrics, timings and font/icon settings in one place — restyle the
whole pill here. Instantiated once in =init.qml= as =Theme { id: theme }= and
passed into every component as a =theme= property (no singletons).

The palette is the warm vermillion/cream scheme borrowed from Ricelin (=accent=
vermillion over a cocoa-black =bg=). At rest the pill is a borderless translucent
gradient (=bgGradTop= → =bgGradBottom=) and slightly dimmed (=idleOpacity=); it
animates to a solid bordered surface the moment it is hovered, opened, or morphed
by a notification. This is alpha translucency only — true backdrop *blur* would
need the KWin blur protocol, which Quickshell does not expose. Icons resolve
through Qt's icon theme; =iconTheme= forces a specific one (e.g. ="Papirus"=), =""=
follows KDE — =run-pill.sh= reads this and applies it (see [[*run-pill.sh][§ run-pill.sh]]).
#+begin_src qml :tangle ~/.config/quickshell/pill/Theme.qml :mkdirp yes

    readonly property color bgHover:     "#34271f"   // hovered rows / tiles

    readonly property color text:        "#e6d6cb"   // cream
    readonly property color textDim:     "#8a7d74"   // dim

    readonly property color accentDim:   "#46291d"   // selected / active background tint
    readonly property color danger:      "#e0563b"   // vermillion-light

    // NOTE: this is alpha translucency only — true backdrop blur needs the KWin

    // resting-pill gradient (translucent, no border): warmer/lighter top fading to
    // a darker bottom, so the floating pill blends with whatever is behind it.
    readonly property color bgGradTop:     Qt.rgba(0x34 / 255.0, 0x27 / 255.0, 0x1f / 255.0, 0.80)

    // reads this value and applies it. "" = follow KDE.
    readonly property string iconTheme:   ""
    readonly property int fsSmall:       11
    readonly property int fsNormal:      13
    readonly property int fsLarge:       15

    // ---- animation ----
    readonly property int anim:          210
    readonly property int animFast:      130
}

        }
    }

    MouseArea {
        anchors.fill: parent
        cursorShape: Qt.PointingHandCursor
        onClicked: {
            root.checked = !root.checked;
            root.toggled(root.checked);
        }
    }
}

** NetworkMenu.qml
Wi-Fi list (signal bars + a lock on secured nets, sorted active-first then by
=signalStrength=), connect/disconnect, and a password overlay calling
=connectWithPsk()= for secured unknown networks; toggles =Networking.wifiEnabled=
and runs the scanner only while visible. Uses native =Quickshell.Networking=.
VPN/WireGuard connections are *not* in that binding, so they are listed and toggled
via =nmcli= (=Process=). A header gear opens KDE's network KCM.
#+begin_src qml :tangle ~/.config/quickshell/pill/NetworkMenu.qml :mkdirp yes
pragma ComponentBehavior: Bound
// NetworkMenu.qml — Wi-Fi list (signal + lock + active), connect/disconnect,
// password prompt for secured networks, Wi-Fi on/off. Uses Quickshell.Networking
// (NetworkManager). VPN connections are NOT in the native binding, so they're
// listed + toggled via `nmcli` (Process). A header gear opens KDE's network KCM.
import QtQuick
import Quickshell.Io
import Quickshell.Networking

Item {
    id: root
    required property var theme
    signal closeRequested()

    // ---- VPN (nmcli, since the native binding has no VPN) ----
    property var vpns: []
    function refreshVpn() { if (!vpnList.running) vpnList.running = true; }
    function setVpn(name, up) {
        vpnToggle.command = ["nmcli", "connection", up ? "up" : "down", "id", name];
        vpnToggle.running = true;
    }
    Process {
        id: vpnList
        command: ["nmcli", "-t", "-f", "NAME,TYPE,STATE", "connection", "show"]
        stdout: StdioCollector {
            onStreamFinished: {
                const out = [];
                for (const line of this.text.split("\n")) {
                    if (!line) continue;
                    // `-t` is colon-separated; TYPE/STATE never contain ':', so the
                    // name is everything before the last two fields (handles ':' in names)
                    const p = line.split(":");
                    if (p.length < 3) continue;
                    const state = p[p.length - 1], type = p[p.length - 2];
                    if (type.indexOf("vpn") === -1 && type.indexOf("wireguard") === -1) continue;
                    out.push({ name: p.slice(0, p.length - 2).join(":"), active: state === "activated" });
                }
                root.vpns = out;
            }
        }
    }
    Process { id: vpnToggle; onExited: root.refreshVpn() }
    Timer { interval: 4000; running: true; repeat: true; onTriggered: root.refreshVpn() }

    // open KDE's network settings — try Plasma 6 then older variants
    Process { id: settingsProc }
    function openNetworkSettings() {
        settingsProc.command = ["sh", "-c",
            "kcmshell6 kcm_networkmanagement || systemsettings kcm_networkmanagement || kcmshell5 kcm_networkmanagement"];
        settingsProc.startDetached();
        root.closeRequested();
    }

    readonly property var wifiDev: {
        const ds = Networking.devices ? Networking.devices.values : [];
        for (let i = 0; i < ds.length; i++)
            if (ds[i].type === DeviceType.Wifi) return ds[i];
        return null;
    }
    readonly property var nets: {
        if (!wifiDev || !wifiDev.networks) return [];
        const a = wifiDev.networks.values.slice();
        a.sort((x, y) => (y.connected - x.connected) || (y.signalStrength - x.signalStrength));
        return a;
    }
    property var pskTarget: null

    Component.onCompleted: { if (wifiDev) wifiDev.scannerEnabled = true; root.refreshVpn(); }
    Component.onDestruction: if (wifiDev) wifiDev.scannerEnabled = false

    Column {
        anchors.fill: parent
        spacing: root.theme.gap

        MenuHeader {                            // back chevron + title + settings gear + Wi-Fi toggle
            theme: root.theme
            title: "Network"
            onBack: root.closeRequested()
            Text {                              // open KDE network settings
                anchors.verticalCenter: parent.verticalCenter
                text: "⚙"
                color: gearMa.containsMouse ? root.theme.text : root.theme.textDim
                font.family: root.theme.family
                font.pixelSize: root.theme.fsLarge
                MouseArea {
                    id: gearMa
                    anchors.fill: parent; anchors.margins: -4
                    hoverEnabled: true; cursorShape: Qt.PointingHandCursor
                    onClicked: root.openNetworkSettings()
                }
            }
            PillToggle {
                theme: root.theme
                anchors.verticalCenter: parent.verticalCenter
                checked: Networking.wifiEnabled
                onToggled: v => Networking.wifiEnabled = v
            }
        }

        Flickable {                             // network list
            width: parent.width
            height: parent.height - 36
            contentHeight: netCol.height
            clip: true
            Column {
                id: netCol
                width: parent.width
                spacing: 4

                // ---- VPN connections (nmcli) — only shown when some exist ----
                Text {
                    visible: root.vpns.length > 0
                    text: "VPN"
                    color: root.theme.textDim
                    font.family: root.theme.family
                    font.pixelSize: root.theme.fsSmall
                    font.bold: true
                }
                Repeater {
                    model: root.vpns
                    delegate: Rectangle {
                        id: vpnRow
                        required property var modelData
                        width: netCol.width
                        height: root.theme.rowHeight
                        radius: root.theme.radiusSmall
                        color: vpnRow.modelData.active ? root.theme.accentDim : root.theme.bgHover
                        Text {
                            anchors.left: parent.left
                            anchors.leftMargin: 10
                            anchors.right: vpnState.left
                            anchors.rightMargin: 8
                            anchors.verticalCenter: parent.verticalCenter
                            elide: Text.ElideRight
                            text: vpnRow.modelData.name
                            color: root.theme.text
                            font.family: root.theme.family
                            font.pixelSize: root.theme.fsNormal
                        }
                        Text {
                            id: vpnState
                            anchors.right: parent.right
                            anchors.rightMargin: 10
                            anchors.verticalCenter: parent.verticalCenter
                            text: vpnRow.modelData.active ? "Disconnect" : "Connect"
                            color: root.theme.textDim
                            font.family: root.theme.family
                            font.pixelSize: root.theme.fsSmall
                        }
                        MouseArea {
                            anchors.fill: parent
                            cursorShape: Qt.PointingHandCursor
                            onClicked: root.setVpn(vpnRow.modelData.name, !vpnRow.modelData.active)
                        }
                    }
                }
                Text {                          // section label for the Wi-Fi list below
                    visible: root.vpns.length > 0
                    text: "Wi-Fi"
                    color: root.theme.textDim
                    font.family: root.theme.family
                    font.pixelSize: root.theme.fsSmall
                    font.bold: true
                }

                Repeater {
                    model: root.nets
                    delegate: Rectangle {
                        id: netRow
                        required property var modelData
                        width: netCol.width
                        height: root.theme.rowHeight
                        radius: root.theme.radiusSmall
                        color: modelData.connected ? root.theme.accentDim : root.theme.bgHover

                        Row {
                            anchors.left: parent.left
                            anchors.leftMargin: 10
                            anchors.verticalCenter: parent.verticalCenter
                            spacing: 8
                            Text {
                                anchors.verticalCenter: parent.verticalCenter
                                text: {
                                    const s = netRow.modelData.signalStrength;
                                    return s > 0.75 ? "▰▰▰▰" : s > 0.5 ? "▰▰▰▱" : s > 0.25 ? "▰▰▱▱" : "▰▱▱▱";
                                }
                                color: root.theme.accent
                                font.family: root.theme.family
                                font.pixelSize: root.theme.fsSmall
                            }
                            Text {
                                anchors.verticalCenter: parent.verticalCenter
                                width: netRow.width - 190
                                elide: Text.ElideRight
                                text: netRow.modelData.name
                                color: root.theme.text
                                font.family: root.theme.family
                                font.pixelSize: root.theme.fsNormal
                            }
                            Text {
                                anchors.verticalCenter: parent.verticalCenter
                                visible: netRow.modelData.security !== WifiSecurityType.Open
                                text: "🔒"
                                font.family: root.theme.family
                                font.pixelSize: root.theme.fsSmall
                            }
                        }
                        Text {
                            anchors.right: parent.right
                            anchors.rightMargin: 10
                            anchors.verticalCenter: parent.verticalCenter
                            text: netRow.modelData.connected ? "Disconnect" : "Connect"
                            color: root.theme.textDim
                            font.family: root.theme.family
                            font.pixelSize: root.theme.fsSmall
                        }
                        MouseArea {
                            anchors.fill: parent
                            cursorShape: Qt.PointingHandCursor
                            onClicked: {
                                const n = netRow.modelData;
                                if (n.connected) { n.disconnect(); return; }
                                if (n.known || n.security === WifiSecurityType.Open) n.connect();
                                else root.pskTarget = n;
                            }
                        }
                    }
                }
            }
        }
    }

    // password prompt overlay (secured + unknown networks)
    Rectangle {
        anchors.fill: parent
        visible: root.pskTarget !== null
        color: root.theme.bg
        radius: root.theme.radiusSmall
        Column {
            anchors.centerIn: parent
            width: parent.width - 24
            spacing: root.theme.gap
            Text {
                width: parent.width
                elide: Text.ElideRight
                text: root.pskTarget ? ("Password for " + root.pskTarget.name) : ""

            Rectangle {
                width: parent.width
                height: 34

                color: root.theme.bgHover
                border.color: root.theme.border

                    id: pskInput
                    anchors.fill: parent
                    anchors.leftMargin: 10
                    anchors.rightMargin: 10
                    verticalAlignment: TextInput.AlignVCenter
                    echoMode: TextInput.Password
                    color: root.theme.text
                    font.family: root.theme.family
                    font.pixelSize: root.theme.fsNormal
                    clip: true
                    focus: root.pskTarget !== null
                    onAccepted: {

                    }
                }
            }
            Row {
                anchors.right: parent.right
                spacing: root.theme.gap
                Text {
                    text: "Cancel"
                    color: root.theme.textDim
                    font.family: root.theme.family
                    font.pixelSize: root.theme.fsNormal

                    color: root.theme.accent
                    font.family: root.theme.family
                    font.pixelSize: root.theme.fsNormal
                    font.bold: true

                            root.pskTarget = null; pskInput.text = "";
                        } }
                }
            }
        }
    }
}

** VolumeMenu.qml
Devices tab (speakers = =Audio/Sink=, mics = =Audio/Source=) with per-device
volume/mute/set-default, and Applications tab (=Stream/Output/Audio=) with
per-stream volume/mute. Uses native =Quickshell.Services.Pipewire=; a
=PwObjectTracker= over every node keeps audio live and nodes are classified by
=media.class=. Header shortcuts open KDE's Audio (=kcm_pulseaudio=) and Multimedia
(=kcm_phonon=) settings.
#+begin_src qml :tangle ~/.config/quickshell/pill/VolumeMenu.qml :mkdirp yes
pragma ComponentBehavior: Bound
// VolumeMenu.qml — Devices tab (speakers = Audio/Sink, mics = Audio/Source) with
// per-device volume/mute/set-default, and Applications tab (Stream/Output/Audio)
// with per-stream volume/mute. Uses Quickshell.Services.Pipewire. Node audio is
// kept live by the PwObjectTracker over every node.
import QtQuick
import Quickshell.Io
import Quickshell.Services.Pipewire

Item {
    id: root
    required property var theme
    signal closeRequested()
    property int tab: 0               // 0 = Devices, 1 = Applications

    // open KDE's audio settings. KDE ships two: "Audio" (kcm_pulseaudio, the
    // volume/devices module) and "Multimedia" (kcm_phonon, backend/device order).
    // Try Plasma 6's kcmshell6, then systemsettings, then the Plasma 5 variants.
    Process { id: settingsProc }
    function openAudioSettings(kcm) {
        settingsProc.command = ["sh", "-c",
            "kcmshell6 " + kcm + " || systemsettings " + kcm + " || kcmshell5 " + kcm];
        settingsProc.startDetached();
        root.closeRequested();
    }

    PwObjectTracker { objects: Pipewire.nodes ? Pipewire.nodes.values : [] }

    function cls(n) { return (n && n.properties) ? (n.properties["media.class"] || "") : ""; }
    readonly property var allNodes: Pipewire.nodes ? Pipewire.nodes.values : []

// called by the parent when the launcher opens: clear + focus the search
function open() { search.text = ""; ctx.app = null; currentIndex = 0; search.forceActiveFocus(); }
// called when the launcher closes: drop the search field's active focus so the
// (kept-instantiated) launcher stops holding the layer surface's keyboard grab,
// letting the focused window get the keyboard back. The parent sets the window's
// WlrKeyboardFocus to None in tandem.
function close() { search.focus = false; ctx.app = null; }

// ---- query / filtering ----
readonly property string q: search.text.trim().toLowerCase()
readonly property bool searching: q.length > 0

function norm(s) { return (s || "").toString().toLowerCase(); }
readonly property var filtered: {
    if (!searching)
        return [];
    const out = [];
    for (const a of apps) {
        if (norm(a.name).indexOf(q) >= 0 || norm(a.genericName).indexOf(q) >= 0) { out.push(a); continue; }
        const kw = a.keywords || [];
        let hit = false;
        for (const k of kw) if (norm(k).indexOf(q) >= 0) { hit = true; break; }
        if (hit) out.push(a);
    }
    return out;
}
readonly property var favApps: {
    const ids = settings.favorites || [];
    if (ids.length === 0) return [];
    const byId = {};
    for (const a of apps) byId[a.id] = a;
    return ids.map(id => byId[id]).filter(Boolean);
}
// searching -> filtered list; else favourites (if any) else everything
readonly property var model: searching ? filtered : (favApps.length > 0 ? favApps : apps)
// grid only on the resting view; searching is always a list
readonly property bool showGrid: !searching && settings.grid

// ---- keyboard selection (arrow-key navigation) ----
// index into `model` of the highlighted item; reset whenever the visible set
// changes (a new query, or toggling grid/list).
property int currentIndex: 0
onQChanged: currentIndex = 0
onShowGridChanged: currentIndex = 0
function setSel(i) {
    const n = model.length;
    currentIndex = n === 0 ? 0 : Math.max(0, Math.min(n - 1, i));
    if (n === 0) return;
    if (showGrid) grid.positionViewAtIndex(currentIndex, GridView.Contain);
    else list.positionViewAtIndex(currentIndex, ListView.Contain);
}
// up/down step one row (or one grid row); left/right step one column. In the
// grid every arrow navigates; in a list up/down navigate, and left/right only
// navigate when the search is empty (otherwise they move the text cursor).
function moveVert(d) { setSel(currentIndex + d * (showGrid ? grid.cols : 1)); }

function activateCurrent() {
    if (calcResult !== null) { copy(calcResult); root.launched(); return; }
    const n = model.length;
    if (n === 0) return;
    model[Math.max(0, Math.min(n - 1, currentIndex))].execute();
    root.launched();
}

    const f = (settings.favorites || []).slice();

// ---- calculator: evaluate a safe arithmetic expression ----
readonly property var calcResult: searching ? evalCalc(search.text.trim()) : null
function evalCalc(expr) {
    let forced = false;
    let e = expr.trim();
    if (e.length > 0 && e[0] === "=") { forced = true; e = e.slice(1).trim(); }
    if (e.length === 0) return null;
    if (!/^[0-9.,+\-*/%()\s]+$/.test(e)) return null;     // digits + operators only
    if (!forced && !/[-+*/%]/.test(e)) return null;       // plain numbers don't count
    e = e.replace(/,/g, "");
    try {
        const r = Function('"use strict"; return (' + e + ');')();
        if (typeof r === "number" && isFinite(r))
            return Number.isInteger(r) ? r : parseFloat(r.toFixed(8));
    } catch (err) {}
    return null;
}

** Notifications.qml
The freedesktop notification *server* + popup/history *state*. Instantiated once
in =init.qml= and shared with every monitor (the morph card, the floating cards
and the history menu). Requires Plasma's own notifications disabled first — see
[[*Taking over notifications from Plasma][§ Taking over notifications from Plasma]].

Every notification is kept =tracked= so it survives as *history*; =grouped= buckets
it by app for the history pane, while a separate =active= stack holds the un-closed
popups. Each popup has its own countdown held centrally in =remaining= keyed by id
(a single =Timer= steps them, since the deck recreates its delegates): *every* popup
is capped at *5s* — a longer app-requested timeout is ignored, a shorter one is
honoured, and =expireTimeout === 0= ("persistent") / Critical urgency are treated as
the 5s cap too, so nothing — not even an indefinite notification — outlives it.
Closing a popup or letting it time out
only drops it from =active= and *keeps* it in history; we avoid =dismiss()/expire()=
because Quickshell would *destroy* the notification (wiping the history copy too),
so only =forget()= / =clearAll()= remove from history.
#+begin_src qml :tangle ~/.config/quickshell/pill/Notifications.qml :mkdirp yes
pragma ComponentBehavior: Bound
// Notifications.qml — the freedesktop notification server + popup/history state.
// Instantiated once in init.qml as `Notifications { id: notifs; theme: theme }`
// and shared with every monitor's views (no singletons). It:
//   * owns a NotificationServer advertising body/markup/images/actions/action-
//     icons/inline-reply/persistence, so apps send us the rich payload;
//   * keeps every notification `tracked` so it survives as *history*
//     (server.trackedNotifications), grouped by app in the history view;
//   * maintains an `active` stack (newest first) of un-closed popups that drive
//     the collapsed-pill morph; each notification has its own countdown (kept in
//     `remaining`, keyed by id), and `held` (set while a deck is hovered) pauses
//     and resets them all. Closing a popup or letting it time out only removes it
//     from `active` and keeps the (tracked) history copy — we never call
//     Notification.dismiss()/expire(), which would *destroy* it. Forget/clear set
//     tracked=false to actually drop a notification from history.
//
// The spec carries no timestamp, so we stamp arrival time ourselves (`stamps`);
// on a Quickshell reload restored notifications are re-stamped to "now".
import QtQuick
import QtQml
import Quickshell
import Quickshell.Services.Notifications

QtObject {
    id: root
    required property var theme

    // ---- the server: the capabilities we advertise to apps ----
    readonly property NotificationServer server: NotificationServer {
        keepOnReload: true
        persistenceSupported: true
        bodySupported: true
        bodyMarkupSupported: true
        bodyImagesSupported: true
        imageSupported: true
        actionsSupported: true
        actionIconsSupported: true
        inlineReplySupported: true
        onNotification: n => root.onArrived(n)
    }

    // ---- arrival timestamps (id -> ms since epoch); the spec carries none ----
    property var stamps: ({})

    // ---- active popup stack (newest first) drives the pill morph ----
    // Per-notification countdowns live HERE (keyed by id), not in the cards: the
    // deck's Repeater recreates its delegates whenever `active` changes, which
    // would otherwise reset every timer on each arrival. `held` (set while a deck
    // is hovered) pauses every countdown and resets them all to full.
    property var active: []
    readonly property var current: active.length ? active[0] : null   // newest
    property bool held: false
    // do-not-disturb: when on, arrivals are still kept for history but never
    // popped (no morph, no floating card). Toggled from the launcher's toggle row.
    property bool dnd: false
    property var remaining: ({})              // id -> ms left
    property int tick: 0                       // bumped each step to refresh progress bindings
    readonly property bool anyReply: {
        for (const n of active) if (n && n.hasInlineReply) return true;
        return false;
    }

    function progressFor(n) {
        root.tick;                            // dependency: re-eval each countdown step
        if (!n) return 0;
        const t = root.timeoutFor(n);
        if (t <= 0) return 0;
        const r = root.remaining[n.id];
        return r === undefined ? 1 : Math.max(0, Math.min(1, r / t));
    }

    readonly property Timer ticker: Timer {
        interval: 50; repeat: true
        running: root.active.length > 0 && !root.held
        onTriggered: {
            const dead = [];
            for (const n of root.active) {
                const t = root.timeoutFor(n);
                if (t <= 0) continue;          // defensive: timeoutFor caps everything > 0
                let r = root.remaining[n.id];
                r = (r === undefined ? t : r) - interval;
                root.remaining[n.id] = r;
                if (r <= 0) dead.push(n);
            }
            root.tick++;                       // refresh progress bars
            for (const n of dead) root.expireOne(n);
        }
    }

    // a 1-second clock so "x min ago" stays fresh in the cards / history
    readonly property var clock: SystemClock { precision: SystemClock.Seconds }
    readonly property double nowMs: clock.date.getTime()

    function onArrived(n) {
        if (!root.stamps[n.id])
            root.stamps[n.id] = (new Date()).getTime();
        n.tracked = true;                     // keep it for history
        // rebuild the grouped history now: setting tracked=true doesn't reliably
        // fire trackedNotificationsChanged for a fresh arrival, so without this the
        // history (and the collapsed-pill unread dot) wouldn't update until the
        // history pane is opened and rebuilds it by hand.
        root.rebuild();
        if (n.lastGeneration)                 // restored on reload: history only, don't re-pop
            return;
        if (root.dnd)                         // do-not-disturb: history only, no popup
            return;
        // de-dupe (apps reuse ids to replace): drop any copy, push to the front
        const a = root.active.filter(x => x.id !== n.id);
        a.unshift(n);
        root.active = a;
        root.remaining[n.id] = root.timeoutFor(n);   // start (or restart) its countdown
        root.tick++;
    }

    readonly property int defaultTimeoutMs: 5000   // hard ceiling: no popup outlives this
    function timeoutFor(n) {
        if (!n) return 0;
        // EVERY popup is capped at 5s — including Critical and an app's
        // "persistent" (0) / "default" (-1) request: honour a *shorter*
        // app-requested timeout, but ignore anything longer or indefinite, so
        // nothing lingers past defaultTimeoutMs.
        const want = n.expireTimeout;
        return (want > 0 && want < root.defaultTimeoutMs) ? want : root.defaultTimeoutMs;
    }

    // remove from the active stack only (the history copy is untouched)
    function drop(n) {
        if (!n) return;
        root.active = root.active.filter(x => x.id !== n.id);
        delete root.remaining[n.id];
        // deck just emptied — clear any stuck hover-hold. The morph deck's
        // HoverHandler is destroyed when the last popup goes (notifMorph turns
        // false); if it was hovered at that moment it never fires hovered=false,
        // leaving `held` true and freezing every *future* popup's countdown.
        if (root.active.length === 0)
            root.held = false;
    }
    // close a popup: stop showing it but ALWAYS KEEP it in history (even the X and
    // even transient notifications — only `forget`/`clearAll` remove from history).
    // We deliberately do NOT call Notification.dismiss()/expire() here — in
    // Quickshell those *destroy* the notification (untracking it), which would wipe
    // the history copy too; the trade-off is the sending app isn't told it closed.
    function closePopup(n) {
        if (!n) return;
        root.drop(n);   // remove from the popup stack; the tracked history copy stays
    }
    function dismiss(n)   { root.closePopup(n); }   // X on a popup
    function expireOne(n) { root.closePopup(n); }   // a countdown elapsed
    // dismiss the whole active popup deck at once (history is kept, like the X)
    function dismissAll() { for (const n of root.active.slice()) root.closePopup(n); }
    function hold(v) {                                // hover: pause + reset every countdown
        root.held = v;
        if (v) {
            for (const n of root.active) root.remaining[n.id] = root.timeoutFor(n);
            root.tick++;
        }
    }

    // remove from history entirely (tracked=false == dismiss(): destroys it).
    // Rebuild *now* rather than waiting for trackedNotificationsChanged: the dying
    // notification can linger in `values` for a cycle with its content already
    // cleared, which would flash an empty card in the history (rebuild filters it).
    function forget(n) { if (n) { root.drop(n); n.tracked = false; root.rebuild(); } }
    function clearAll() {
        const all = root.server.trackedNotifications ? root.server.trackedNotifications.values.slice() : [];
        for (const n of all) n.tracked = false;
        root.active = [];
        root.rebuild();
    }
    // clear one history group (an app's notifications) at once — like clearAll,
    // scoped to the group's items (the "Clear" button on a group header).
    function clearGroup(g) {
        if (!g || !g.items) return;
        for (const n of g.items.slice()) { root.drop(n); n.tracked = false; }
        root.rebuild();
    }

    // ---- watch each tracked notification's `closed` (e.g. the sender closed or
    //      replaced it) so it leaves the active stack too ----
    readonly property Instantiator watcher: Instantiator {
        model: root.server.trackedNotifications
        delegate: Connections {
            required property var modelData
            target: modelData
            function onClosed(reason) { root.drop(modelData); }
        }
    }

    // ---- grouped history: by app, newest-first within a group, group ordered by
    //      its newest item, so a fresh notification floats its app to the top ----
    property var grouped: []
    function rebuild() {
        const list = root.server.trackedNotifications ? root.server.trackedNotifications.values : [];
        const ts = id => root.stamps[id] || 0;
        const by = {}, order = [];
        for (const n of list) {
            // a just-forgotten notification can still appear in `values` for one
            // cycle (emptied of content) while it is being destroyed — skip it so
            // history never shows a contentless card.
            if (!n || !n.tracked) continue;
            const k = n.appName || "Unknown";
            if (!by[k]) { by[k] = { app: k, items: [] }; order.push(k); }
            by[k].items.push(n);
        }
        for (const k of order) by[k].items.sort((x, y) => ts(y.id) - ts(x.id));
        const gs = order.map(k => by[k]);
        gs.sort((g1, g2) => ts(g2.items[0].id) - ts(g1.items[0].id));
        root.grouped = gs;
    }
    readonly property Connections rebuilder: Connections {
        target: root.server
        function onTrackedNotificationsChanged() { root.rebuild(); }
    }
    Component.onCompleted: root.rebuild()

    function relTime(id) {
        const t = root.stamps[id]; if (!t) return "";
        let s = Math.floor((root.nowMs - t) / 1000); if (s < 0) s = 0;

        return Math.floor(h / 24) + "d ago";

#!/usr/bin/env python
# winbridge.py — feeds the pill its open-window list + the active window.
#
# Why this exists: KWin (Wayland) exposes NO window-list protocol to clients and
# NO active-window over DBus. So we use two KDE APIs and glue them:
#   * the KRunner "windows" runner (org.kde.KWin /WindowsRunner) lists windows
#     (id, title, app-icon name) and is polled here;
#   * a 3-line KWin script (loaded below via /Scripting) reports the active
#     window's id whenever it changes, by calling our own org.kde.pill service.
# We print one JSON line {"active": "{uuid}", "windows": [...]} per update; the
# pill reads it on stdout. Launched by init.qml as `python <shellDir>/winbridge.py`.
import sys, os, json, atexit, tempfile
from gi.repository import Gio, GLib

bus = Gio.bus_get_sync(Gio.BusType.SESSION, None)
# "taskbar" is the set of window ids that belong in a taskbar (normal, not
# skip-taskbar) as reported by KWin; None until the first report arrives.
state = {"active": "", "taskbar": None, "fullscreen": False}
PLUGIN = "quickshell-pill-active"

# --- our DBus service ---
#   Set(uuid, fs)  — KWin script reports the active window (+ "1"/"0" fullscreen)
#   List(json)     — KWin script reports the taskbar-eligible window ids (JSON array)
#   Launcher(scr)  — KWin global shortcut asks the pill to toggle the launcher on
#                    the screen named `scr` (empty = whichever pill is on it)
NODE = (
    '<node><interface name="org.kde.pill">'
    '<method name="Set"><arg type="s" direction="in"/><arg type="s" direction="in"/></method>'
    '<method name="List"><arg type="s" direction="in"/></method>'
    '<method name="Launcher"><arg type="s" direction="in"/></method>'
    "</interface></node>"
)
IFACE = Gio.DBusNodeInfo.new_for_xml(NODE).interfaces[0]


def on_call(conn, sender, path, ifc, method, params, inv):
    if method == "Set":
        (u, fs) = params.unpack()
        state["active"] = u
        state["fullscreen"] = fs == "1"
        emit()
    elif method == "List":
        (j,) = params.unpack()
        try:
            state["taskbar"] = set(json.loads(j))
        except Exception:
            state["taskbar"] = None
        emit()
    elif method == "Launcher":
        (scr,) = params.unpack()
        # one-off event line (not the regular state snapshot) the pill reacts to
        sys.stdout.write(json.dumps({"event": "launcher", "screen": scr}) + "\n")
        sys.stdout.flush()
    inv.return_value(None)


def on_bus_acquired(conn, name):
    conn.register_object("/Active", IFACE, on_call, None, None)
    load_kwin_script()


# --- the KWin script: reports the active window (+ its fullscreen flag) AND the
#     taskbar-eligible window ids (normal windows that don't ask to skip the
#     taskbar). KWin is the only place skipTaskbar / fullScreen are exposed;
#     KRunner (used for icon names) is not. We re-push the list on add/remove and
#     on skipTaskbar changes, and re-push the active window when *its* fullScreen
#     toggles (e.g. a video going fullscreen without re-activating the window). ---
KWIN_JS = (
    "function ids(){ var ws=workspace.windowList(), o=[];\n"
    "  for (var i=0;i<ws.length;i++){ var w=ws[i];\n"
    "    if (w.normalWindow && !w.skipTaskbar) o.push(String(w.internalId)); }\n"
    "  return o; }\n"
    'function pushList(){ callDBus("org.kde.pill","/Active","org.kde.pill","List",'
    " JSON.stringify(ids())); }\n"
    'function setActive(w){ callDBus("org.kde.pill","/Active","org.kde.pill","Set",'
    ' w ? String(w.internalId) : "", (w && w.fullScreen) ? "1" : "0"); }\n'
    "function watch(w){ if (!w) return;\n"
    "  if (w.skipTaskbarChanged) w.skipTaskbarChanged.connect(pushList);\n"
    "  if (w.fullScreenChanged) w.fullScreenChanged.connect(function(){\n"
    "    if (w === workspace.activeWindow) setActive(w); }); }\n"
    "workspace.windowActivated.connect(setActive);\n"
    "workspace.windowAdded.connect(function(w){ watch(w); pushList(); });\n"
    "workspace.windowRemoved.connect(pushList);\n"
    "var all=workspace.windowList(); for (var i=0;i<all.length;i++) watch(all[i]);\n"
    "setActive(workspace.activeWindow);\n"
    "pushList();\n"
    # global shortcut (Meta+D) to toggle the launcher; passes the focused window's
    # screen so the right monitor's pill opens. Configurable in System Settings ->
    # Shortcuts -> KWin once registered.
    "function scr(){ var w=workspace.activeWindow; return (w && w.output) ? w.output.name : ''; }\n"
    'registerShortcut("PillLauncher","Pill: open launcher","Meta+D",function(){\n'
    '  callDBus("org.kde.pill","/Active","org.kde.pill","Launcher", scr()); });\n'
)


def kwin(method, variant):
    try:
        bus.call_sync(
            "org.kde.KWin",
            "/Scripting",
            "org.kde.kwin.Scripting",
            method,
            variant,
            None,
            Gio.DBusCallFlags.NONE,
            2000,
            None,
        )
    except Exception as e:
        sys.stderr.write("winbridge: %s failed: %s\n" % (method, e))

    path = os.path.join(tempfile.gettempdir(), "quickshell_pill_active.js")

    kwin("unloadScript", GLib.Variant("(s)", (PLUGIN,)))  # clear a stale copy
    kwin("loadScript", GLib.Variant("(ss)", (path, PLUGIN)))

# --- poll the KRunner windows runner for the window list ---
def windows():
    try:
        res = bus.call_sync(
            "org.kde.KWin",
            "/WindowsRunner",
            "org.kde.krunner1",
            "Match",
            GLib.Variant("(s)", ("",)),
            GLib.VariantType("(a(sssida{sv}))"),
            Gio.DBusCallFlags.NONE,
            3000,
            None,
        )
    except Exception:
        return []
    tb = state["taskbar"]
    seen = {}
    for m in res.unpack()[0]:
        mid, text, icon = m[0], m[1], m[2]  # id, title, icon name
        if not mid.startswith("0_") or mid in seen:
            continue
        # KWin briefly lists an internal placeholder window (icon "kwin", no title)
        # while a window is being activated; it would flash a phantom app tile in
        # the taskbar for a frame, so drop it — no real app uses the "kwin" icon.
        if icon == "kwin":
            continue
        uuid = mid[2:]
        # once KWin has reported the eligible set, drop skip-taskbar windows;
        # before the first report, show everything (previous behaviour)
        if tb is not None and uuid not in tb:
            continue
        seen[mid] = {"id": mid, "uuid": uuid, "title": text, "icon": icon}
    return sorted(seen.values(), key=lambda d: d["id"])


def emit():
    line = json.dumps(
        {
            "active": state["active"],
            "fullscreen": state["fullscreen"],
            "windows": windows(),
        },
        ensure_ascii=False,
    )
    sys.stdout.write(line + "\n")
    sys.stdout.flush()

    emit()
    return True

** init.qml
The entry point and long-lived root: it owns the per-monitor windows, the stage
machine, virtual desktops, the taskbar/tray UI, action bursts, and hosts the menus
and launcher. Sibling =.qml= files are used as component types via QML's implicit
directory import; =Theme= is instantiated once here and passed to each menu as
=theme= (no singletons).

*Window & input model.* =Variants { model: Quickshell.screens }= makes one
full-screen layer-shell =Overlay= =PanelWindow= per monitor that reserves no space.
The window =mask= governs input: collapsed/hovered → only the pill rectangle catches
clicks (the rest passes through); open/launcher/right-click → the whole window, where
a backdrop =MouseArea= swallows outside clicks to close (never passed through);
fullscreen-hide (=win.fsHide=, set while a fullscreen window is focused and the pill
is at true rest) → an empty region, so the window is fully click-through and the pill
fades to opacity 0. A notification still morphs through (=notifMorph= overrides
=fsHide=).

*Stages.* A single =pill= =Item= animates =width=/=height= between stages via
=Behavior=, cross-fading content layers per stage:
1. *collapsed* (56×28): =hh:mm=.
2. *hovered* (=dash=, 520×104): two balanced rows — Row 1 desktop dots (left) |
   grouped app icons (right); Row 2 a launcher button + date/time (left) | status
   icons (network/volume/bluetooth/battery/notifications) + system tray (right).
3. *open* (470 tall): control panel. Both rows stay visible; Row 2 doubles as the
   menu switcher (active icon highlighted). A =Loader= below a divider shows the menu
   for =win.menu= (default 4 = notification history); each menu's =MenuHeader=
   chevron collapses the panel via =closeRequested()=.
4. *launcher* (600×470): the launcher takes the menu pane's place (see
   [[*Launcher.qml][§ Launcher.qml]]).

*Keyboard focus.* The surface grabs the keyboard only while a panel is open:
launcher → =Exclusive= (focuses even when opened by the shortcut; arrow nav works),
open menu → =OnDemand= (a password field focuses on click), else =None=. KWin does
*not* restore focus when a layer surface releases the keyboard, so the pill remembers
the last real active window (=lastActiveWindow=, from =winbridge=) and =restoreFocus()=
re-activates it via the KRunner =Run= whenever the pill is dismissed *without*
launching; launching an app skips the restore.

*Global shortcut (Meta+D).* Quickshell's =GlobalShortcut= is Hyprland-only, so the
launcher shortcut rides the KWin script in =winbridge.py= (see [[*winbridge.py][§ winbridge.py]]):
its =\{event:"launcher", screen\}= line becomes the =launcherShortcut(screen)= signal,
and each monitor toggles its launcher if the screen matches.

*Taskbar.* =appGroups= groups =windows= (from =winbridge=) by =icon= — one tile per
app, a count badge for ≥2 windows, an underline that turns accent when any of the
app's windows is active. Left-click =cycleGroup= focuses the app's next window;
right-click opens a floating menu (this app's windows + =DesktopEntries.heuristic-
Lookup(icon).actions=). The =mask= expands full-screen while that menu is open
(=win.ctxGroup=).

*Virtual desktops.* Three =Process= blocks drive =gdbus= against =org.kde.KWin
/VirtualDesktopManager=: fetch the =desktops= list (a regex parses the tuples), fetch
=current=, and =gdbus monitor= =currentChanged= to stay live; =switchDesktop(id)=
sets the writable =current= property.

*Action bursts.* A transient burst briefly (1s) takes over the resting pill then
reverts to the clock, driven from =root= so every monitor shows it (=burstDesk= /
=burstLang= / =burstPhase=; one =Timer= runs settle 100ms → animate 300ms → settle
600ms). Each kind is a mini-pill carrying the hovered surface; both kinds at once sit
side by side and *pop apart* on entry (=Translate=, =OutBack=). A burst takes over
only the resting pill (yields to hover/open/launcher/right-click) and overrides
=notifMorph= so an active notification deck floats below instead of being replaced.
Two events fire bursts, each guarding its initial value on startup:
- *desktop switch* (=onCurrentDesktopChanged=) — a filled dot slides from the old
  slot to the new across the animate phase; the hovered Row-2 dots use the same slide.
- *layout change* (=onKbIndexChanged=) — shows =from → to= (e.g. =US → FA=) with the
  arrow flashing. Layouts come from KWin's =org.kde.keyboard /Layouts= (custom label
  if set in System Settings, else the uppercased code).

*Notifications & launcher hosting.* The =Notifications= object (=notifs=) and the
shared =appList= (=DesktopEntries.applications=, =noDisplay= filtered, name-sorted)
are built once here and shared with every monitor. The collapsed pill *morphs* into
the active-popup deck when a notification arrives and the pill isn't open (the clock
hides and =pill.height= tracks the deck); while open/launcher/app-menu the deck floats
*below* instead. The launcher field is focused + cleared on each open and its focus
dropped on close (so the pill releases the keyboard).

*Privacy indicators.* At rest the pill also flags a live *camera* (any process
holding a =/dev/video*= node open, polled every 2s with =fuser=) or an *unmuted
mic* (the default Pipewire source). Either drops the idle translucency — the
collapsed pill goes solid (real surface + border, no gradient, full-opacity clock)
— and shows a small icon next to the clock (=camera-web= / =audio-input-microphone=;
both side by side when both are live, widening the pill). The icons *pop in* and
*shrink out* like the action bursts (scale overshoots on appear via =OutBack=, the
slot width animates so the clock slides over). It also keeps the pill visible over a
fullscreen window, where it would otherwise hide.

The transient action-burst state machine (desktop switch / layout change): the
=burst*= state, the shared three-phase timeline =Timer=, and the change handlers that
fire a burst on a *real* change. The visuals live in [[*ActionBurstPill.qml][=ActionBurstPill=]].
#+name: init-action-bursts
#+begin_src qml

// ---- transient action bursts (desktop switch / layout change) ----
// A 1s overlay that briefly takes over the resting pill to show what just
// changed, then reverts: phase 1 settle (100ms) -> phase 2 animate (300ms)
// -> phase 3 settle (600ms) -> done. Driven from root so every monitor's
// pill shows it; the pill suppresses notifMorph while bursting and floats
// the notification deck below instead (so notifications slide down). Both kinds
// can be live at once (a desktop switch + a layout change within the same
// window) — then *two* pills show side by side and pop apart on entry.
property bool   burstDesk: false
property bool   burstLang: false
readonly property bool burstActive: burstDesk || burstLang
readonly property var  burstKinds: {       // canonical order: desktops then language
    const a = [];
    if (burstDesk) a.push("desktops");
    if (burstLang) a.push("language");
    return a;
}
property int    burstPhase: 0      // 0 idle, 1 pre, 2 animate, 3 post
property string burstFromDesktop: ""
property string burstToDesktop: ""
property string burstFromLabel: ""
property string burstToLabel: ""
// index of the active desktop (also drives the sliding dot in the hovered Row 2)
readonly property int deskActiveIdx: desktops.findIndex(d => d.id === currentDesktop)
readonly property int burstFromIdx: desktops.findIndex(d => d.id === burstFromDesktop)
readonly property int burstToIdx:   desktops.findIndex(d => d.id === burstToDesktop)
// index of the moving active dot: the new slot once we start animating
readonly property int burstDotIdx: burstPhase >= 2 ? Math.max(0, burstToIdx)
                                                   : Math.max(0, burstFromIdx)
function startBurst(kind) {
    if (kind === "desktops") burstDesk = true;
    else if (kind === "language") burstLang = true;
    burstPhase = 1;                // (re)start the shared timeline from the top
    burstTimer.restart();
}
Timer {
    id: burstTimer
    interval: root.burstPhase === 1 ? 100 : root.burstPhase === 2 ? 300 : 600
    repeat: false
    onTriggered: {
        if (root.burstPhase < 3) { root.burstPhase++; burstTimer.restart(); }
        else { root.burstPhase = 0; root.burstDesk = false; root.burstLang = false; }
    }
}
// fire the bursts on a *real* change (skip the initial value on startup; QML
// change handlers don't carry the old value, so we keep the previous one).
property string prevDesktop: ""
property int    prevKbIndex: -1
onCurrentDesktopChanged: {
    if (prevDesktop === "") { prevDesktop = currentDesktop; return; }
    if (currentDesktop === prevDesktop || currentDesktop === "") return;
    burstFromDesktop = prevDesktop;
    burstToDesktop = currentDesktop;
    prevDesktop = currentDesktop;
    startBurst("desktops");
}
onKbIndexChanged: {
    if (prevKbIndex === -1) { prevKbIndex = kbIndex; return; }
    if (kbIndex === prevKbIndex) return;
    burstFromLabel = prevKbIndex < kbLayouts.length ? kbLayouts[prevKbIndex] : "";
    burstToLabel = kbIndex < kbLayouts.length ? kbLayouts[kbIndex] : "";
    prevKbIndex = kbIndex;
    startBurst("language");
}

            opacity: win.showBurst ? 1 : (win.fsHide ? 0 : ((win.dash || win.notifMorph || win.privacyRest) ? 1 : theme.idleOpacity))

            HoverHandler {
                id: hover
            }

            Rectangle {
                anchors.fill: parent
                radius: (win.open || win.launcher) ? Math.min(theme.radius, height / 2) : 12
                // hovered/open is a solid surface; at rest it's a borderless
                // translucent *gradient* so the floating pill blends with the
                // backdrop. The morph drops the background entirely (cards only);
                // so does a burst — its own pill(s) carry the surface, and the
                // transparent gap shows through when two of them are side by side.
                // a live camera/mic makes the resting pill solid too (no gradient,
                // a real surface + border) so the privacy state reads at a glance.
                color: win.notifMorph ? "transparent" : ((win.dash || win.privacyRest) ? theme.bg : "transparent")
                gradient: (win.dash || win.notifMorph || win.showBurst || win.privacyRest) ? null : restGrad
                border.color: theme.border
                border.width: (!win.notifMorph && (win.dash || win.privacyRest)) ? 1 : 0

                Gradient {
                    id: restGrad

                    GradientStop {
                        position: 0
                        color: theme.bgGradTop
                    }

                    GradientStop {
                        position: 1
                        color: theme.bgGradBottom
                    }

                }

                Behavior on radius {
                    NumberAnimation {
                        duration: theme.anim
                    }

                }

                Behavior on color {
                    ColorAnimation {
                        duration: theme.animFast
                    }

                }

            }

            // clicking the hovered pill body (empty area) opens the launcher;
            // the Row-2 status icons / app icons handle their own clicks above
            MouseArea {
                anchors.fill: parent
                enabled: win.dash && !win.open && !win.launcher && !win.notifMorph
                onClicked: {
                    win.launcher = true;
                }
            }

            MouseArea {
                anchors.fill: parent
                enabled: win.open || win.launcher
                onClicked: {
                }
            }

            // ---- collapsed: clock (hh:mm) + privacy icons (camera / mic) ----
            CollapsedPill {
                anchors.centerIn: parent
                visible: !win.dash && !win.notifMorph && !win.showBurst
                theme: theme
                clock: root.clockShort
                solid: win.privacyRest
                cameraOn: root.cameraInUse
                micOn: root.micActive
                hasUnread: notifs.grouped.length > 0
            }

            // ---- notification morph: the collapsed pill becomes a stack ----
            // The active-notification deck (NotificationStack) is the pill
            // body; pill.height tracks its implicit height, which grows when
            // hovered and the deck drops into a full list. The pill's own
            // background is hidden here so the cards are the only surface.
            Item {
                anchors.fill: parent
                clip: true

                Loader {
                    id: morphStack

                    anchors.horizontalCenter: parent.horizontalCenter
                    y: 0
                    active: win.notifMorph
                    sourceComponent: cStack
                    opacity: win.notifMorph ? 1 : 0
                    visible: opacity > 0

                    Behavior on opacity {
                        NumberAnimation {
                            duration: theme.animFast
                        }

                    }

                }

            }

            // ---- action burst overlay (desktop switch / layout change) ----
            // Replaces the collapsed clock for 1s; one mini-pill per burst kind.
            Loader {
                id: burstLoader

                anchors.centerIn: parent
                active: win.showBurst
                sourceComponent: cBurst
                opacity: win.showBurst ? 1 : 0
                visible: opacity > 0

                Behavior on opacity {
                    NumberAnimation {
                        duration: theme.animFast
                    }

                }

            }

            // ================= Row 1: datetime (left) | apps (right) =================
            Item {
                x: theme.pad
                y: 12
                width: pill.width - theme.pad * 2
                height: 26
                opacity: (win.dash && !win.notifMorph) ? 1 : 0
                visible: opacity > 0

                // virtual desktops
                Row {
                    anchors.left: parent.left
                    anchors.verticalCenter: parent.verticalCenter
                    spacing: 4

                    // time over date
                    Column {
                        anchors.verticalCenter: parent.verticalCenter
                        spacing: 0

                        // big time, prominent
                        Text {
                            text: root.clockShort
                            color: theme.text
                            font.family: theme.mono
                            font.pixelSize: theme.fsLarge
                            font.bold: true
                            lineHeight: 0.95
                        }

                        // date, dim underneath
                        Text {
                            text: root.clockDate
                            color: theme.textDim
                            font.family: theme.family
                            font.pixelSize: theme.fsSmall
                            lineHeight: 0.95
                        }

                    }

                }

                // grouped app icons (taskbar)
                Taskbar {
                    anchors.right: parent.right
                    anchors.verticalCenter: parent.verticalCenter
                    theme: theme
                    groups: root.appGroups
                    activeWindow: root.activeWindow
                    onActivated: (grp) => {
                        return root.cycleGroup(grp);
                    }
                    onContextRequested: (grp) => {
                        return win.ctxGroup = grp;
                    }
                }

                Behavior on opacity {
                    NumberAnimation {
                        duration: theme.animFast
                    }

                }

            }

            // ============ Row 2: launcher icon + virtual desktops (left) | status + tray (right) ============
            Item {
                x: theme.pad
                y: 62
                width: pill.width - theme.pad * 2
                height: 24
                opacity: (win.dash && !win.notifMorph) ? 1 : 0
                visible: opacity > 0

                // launcher button + date/time (left)
                Row {
                    anchors.left: parent.left
                    anchors.verticalCenter: parent.verticalCenter
                    spacing: 10

                    // open the app launcher
                    Rectangle {
                        anchors.verticalCenter: parent.verticalCenter
                        width: 32
                        height: 26
                        radius: theme.radiusSmall
                        color: launchMa.containsMouse ? theme.bgHover : "transparent"

                        IconImage {
                            anchors.centerIn: parent
                            implicitSize: 18
                            source: Quickshell.iconPath("view-grid-symbolic", "view-grid")
                        }

                        MouseArea {
                            id: launchMa

                            anchors.fill: parent
                            hoverEnabled: true
                            cursorShape: Qt.PointingHandCursor
                            onClicked: {
                                win.open = false;
                                win.launcher = true;
                            }
                        }

                        Behavior on color {
                            ColorAnimation {
                                duration: theme.animFast
                            }

                        }

                    }

                    // hollow dots (click to switch) + one filled dot that slides
                    // to the active desktop — the same move as the desktop burst.
                    DesktopDots {
                        anchors.verticalCenter: parent.verticalCenter
                        theme: theme
                        desktops: root.desktops
                        activeIdx: root.deskActiveIdx
                        interactive: true
                        onSwitchRequested: (id) => {
                            return root.switchDesktop(id);
                        }
                    }

                }

                // status icons + system tray (right)
                Row {
                    anchors.right: parent.right
                    anchors.verticalCenter: parent.verticalCenter
                    spacing: 8

                    // status icons -> open panel to that menu (active one highlighted)
                    StatusIcons {
                        theme: theme
                        open: win.open
                        menu: win.menu
                        // close the launcher too, else both panes stack on top of each other
                        onMenuRequested: (m) => {
                            win.launcher = false;
                            win.menu = m;
                            win.open = true;
                        }
                    }

                    // system tray
                    Repeater {
                        model: SystemTray.items

                        delegate: Item {
                            required property SystemTrayItem modelData

                            width: 18
                            height: 18

                            Image {
                                anchors.fill: parent
                                source: modelData.icon
                                fillMode: Image.PreserveAspectFit
                            }

                            MouseArea {
                                anchors.fill: parent
                                acceptedButtons: Qt.LeftButton | Qt.RightButton
                                onClicked: (mouse) => {
                                    if (mouse.button === Qt.LeftButton)
                                        modelData.activate();
                                    else
                                        modelData.display(win, width / 2, height);
                                }
                            }

                        }

                    }

                }

                Behavior on opacity {
                    NumberAnimation {
                        duration: theme.animFast
                    }

                }

            }

            // ===================== control panel (open) =====================
            // Sits below the two dashboard rows (which stay visible; Row 2
            // doubles as the menu switcher). Full-width — no icon rail; each
            // menu carries its own back chevron + title via MenuHeader.
            Item {
                x: theme.pad
                y: 92
                width: pill.width - theme.pad * 2
                height: pill.height - 92 - theme.pad
                opacity: win.open ? 1 : 0
                visible: opacity > 0

                Rectangle {
                    width: parent.width
                    height: 1
                    color: theme.divider
                }

                // menu pane (full width)
                Item {
                    y: 14
                    width: parent.width
                    height: parent.height - 14

                    Loader {
                        id: menuLoader

                        anchors.fill: parent
                        active: win.open
                        sourceComponent: win.menu === 0 ? cNet : win.menu === 1 ? cVol : win.menu === 2 ? cBt : win.menu === 3 ? cBatt : cNotif
                    }
                    // chevron back -> collapse panel

                    Connections {
                        function onCloseRequested() {
                            win.open = false;
                            root.restoreFocus();
                        }

                        target: menuLoader.item
                        ignoreUnknownSignals: true
                    }

                }

                Behavior on opacity {
                    NumberAnimation {
                        duration: theme.anim
                    }

                }

            }

            // ===================== launcher (wider open state) =====================
            // Like the control panel: sits below the two dashboard rows (which
            // stay visible), with a divider on top.
            Item {
                x: theme.pad
                y: 92
                width: pill.width - theme.pad * 2
                height: pill.height - 92 - theme.pad
                clip: true
                opacity: win.launcher ? 1 : 0
                visible: opacity > 0

                Rectangle {
                    width: parent.width
                    height: 1
                    color: theme.divider
                }

                // Kept instantiated (not gated on win.launcher) so the list
                // virtualises and pre-warms its icons in the background at
                // startup; subsequent opens are instant. Sized to the open
                // dimensions regardless of the pill's current animation so
                // the ListView always has room to lay out; the panel clips.
                Launcher {
                    id: launcherItem

                    y: 14
                    width: win.launcherWidth - theme.pad * 2
                    height: win.openHeight - 92 - theme.pad - 14
                    theme: theme
                    apps: root.appList
                    settings: settings
                    notifs: notifs
                    onLaunched: win.launcher = false
                    onCloseRequested: {
                        win.launcher = false;
                        root.restoreFocus();
                    }
                }

                // focus the search field on open; release it on close so the
                // pill drops the keyboard grab and the active window gets it back
                Connections {
                    function onLauncherChanged() {
                        if (win.launcher)
                            launcherItem.open();
                        else
                            launcherItem.close();
                    }

                    target: win
                }

                Behavior on opacity {
                    NumberAnimation {
                        duration: theme.anim
                    }

                }

            }

            Behavior on width {
                NumberAnimation {
                    duration: theme.anim
                    easing.type: Easing.OutCubic
                }

            }

            Behavior on height {
                NumberAnimation {
                    duration: theme.anim
                    easing.type: Easing.OutCubic
                }

            }

            Behavior on opacity {
                NumberAnimation {
                    duration: theme.animFast
                }

            }

        }

        // ===================== app right-click menu =====================
        Loader {
            active: win.ctxGroup !== null
            anchors.horizontalCenter: parent.horizontalCenter
            y: pill.y + pill.height + 6

            sourceComponent: AppContextMenu {
                theme: theme
                group: win.ctxGroup
                onLaunchRequested: (s) => {
                    return root.launch(s);
                }
                onActivateRequested: (id) => {
                    return root.activateWindow(id);
                }
                onDismissed: win.ctxGroup = null
            }

        }

        // ===================== notifications below an open pill =====================
        // When the pill is clicked-open / launcher / app-menu — or briefly while
        // an action burst takes over the pill — notifications don't morph it: the
        // same deck floats below instead (so a burst pushes notifications down).
        Loader {
            anchors.horizontalCenter: parent.horizontalCenter
            y: pill.y + pill.height + 8
            active: ((win.open || win.launcher || win.ctxGroup !== null) || win.showBurst) && notifs.active.length > 0
            sourceComponent: cStack
        }

    }

}

** run-pill.sh
The launch script (=./run-pill.sh=). Qt picks its platform plugin before any QML
loads, so the Wayland socket and the icon theme (see [[*Look, translucency & icons][§ Look, translucency & icons]])
have to be resolved here, not in =init.qml=.
#+begin_src sh :tangle ~/.config/quickshell/pill/run-pill.sh :mkdirp yes :tangle-mode (identity #o755)
#!/bin/sh
# run-pill.sh — launch the pill with a Wayland environment resolved at runtime.
#
# After a reboot the login shell often has no WAYLAND_DISPLAY / QT_QPA_PLATFORM
# exported, so Qt falls back to the xcb plugin, fails to connect, and crashes.
# Qt selects its platform plugin before any QML is parsed, so this has to be
# fixed in the launcher rather than in init.qml. We discover the compositor's
# socket from XDG_RUNTIME_DIR and point Qt at it.
#
# Usage:  ./run-pill.sh            (runs quickshell/init.qml next to this script)
#         ./run-pill.sh <args>     (extra args are forwarded to qs)

set -eu

dir=$(CDPATH= cd -- "$(dirname -- "$0")" && pwd)

# XDG_RUNTIME_DIR is where the wayland socket lives; derive it if absent.
: "${XDG_RUNTIME_DIR:=/run/user/$(id -u)}"
export XDG_RUNTIME_DIR

# If we weren't handed a display, find the compositor's socket.
# Prefer wayland-0, else the first wayland-N socket present.
if [ -z "${WAYLAND_DISPLAY:-}" ]; then
    if [ -S "$XDG_RUNTIME_DIR/wayland-0" ]; then
        WAYLAND_DISPLAY=wayland-0
    else
        for sock in "$XDG_RUNTIME_DIR"/wayland-*; do
            case "$sock" in
                *.lock) continue ;;
            esac
            [ -S "$sock" ] || continue
            WAYLAND_DISPLAY=$(basename "$sock")
            break
        done
    fi
fi

if [ -z "${WAYLAND_DISPLAY:-}" ]; then
    echo "run-pill.sh: no wayland socket found in $XDG_RUNTIME_DIR" >&2
    exit 1
fi
export WAYLAND_DISPLAY
export QT_QPA_PLATFORM=wayland

# Icon theme. Icons (launcher app list, status/tray glyphs) resolve through Qt's
# icon theme. By default we load the KDE Qt platform theme so they follow KDE's
# configured icon theme (System Settings -> Icons). If Theme.qml sets
# `iconTheme: "Name"`, force that instead via the gtk3 platform theme, which reads
# an icon-theme name from a settings.ini we own (Qt has no env var for it). This
# keeps the override self-contained (XDG_CONFIG_HOME is prefixed, not replaced).
icon_theme=$(sed -n 's/.*property[[:space:]][[:space:]]*string[[:space:]][[:space:]]*iconTheme:[[:space:]]*"\([^"]*\)".*/\1/p' "$dir/Theme.qml" 2>/dev/null | head -n1)
if [ -n "${icon_theme:-}" ]; then
    cfg="${XDG_STATE_HOME:-$HOME/.local/state}/quickshell-pill"
    mkdir -p "$cfg/gtk-3.0"
    printf '[Settings]\ngtk-icon-theme-name=%s\n' "$icon_theme" >"$cfg/gtk-3.0/settings.ini"
    export XDG_CONFIG_HOME="$cfg:${XDG_CONFIG_HOME:-$HOME/.config}"
    export QT_QPA_PLATFORMTHEME=gtk3
else
    export QT_QPA_PLATFORMTHEME=kde
fi

exec qs -p "$dir/init.qml" "$@"
#+end_src

* Tangling (how to regenerate the =.qml= files)

This file owns the code; the =.qml= files *and* =winbridge.py= are *generated*.
=C-c C-v t= (=org-babel-tangle=) tangles *all* blocks at once to their =:tangle=
targets in this directory. (Editing a generated file directly is lost on the next
tangle — change it here instead.) Note: launching the pill makes =winbridge.py=
load a small KWin script (=quickshell-pill-active=); it is unloaded when the
bridge exits.

The two big files — [[*init.qml][=init.qml=]] and [[*Launcher.qml][=Launcher.qml=]] —
are *assembled from =noweb= chunks*: the =:tangle … :noweb yes= block holds the
skeleton and pulls each section in by name (=<<init-privacy>>=, …), and every chunk
lives under its own =*** = subheading (with notes) so a section can be read and moved
on its own. Tangle order follows the =<<…>>= references, not the order of the
subheadings, so reordering or relocating a chunk's subtree is safe. Each unnamed block
(=Theme.qml=, the menus, the extracted chrome components, …) still tangles 1:1 to its
own file. After editing any block:

- In Emacs with this file open: =C-c C-v t=.
- Or batch / shell:
  =emacs --batch -l org -eval '(org-babel-tangle-file "quickshell/qs-pill-docs.org")'=

Then validate:  =qs -p quickshell/init.qml=  (Ctrl-C to stop). A clean load prints
"Configuration Loaded" with no WARN lines.

Tangling is *manual on purpose* (matches how I tangle the rest of my config). For
auto-tangle on save, add to the very top of this file:
=# -*- eval: (add-hook 'after-save-hook #'org-babel-tangle nil t) -*-= and accept
the local-variable prompt — but the default here is manual.
